# `docs/` — lo que se lee

| Fichero | Para quién |
|---|---|
| [`adopting.md`](adopting.md) | **empieza aquí si quieres instalarlo.** De un clon limpio a responder preguntas, cronometrado |
| [`use-cases.md`](use-cases.md) | los siete casos de uso con sus criterios de aceptación. Cada uno es un test |
| [`writing-an-adapter.md`](writing-an-adapter.md) | cómo escribir un tercer adaptador contra fuentes que no sean iCalendar, LDAP y CSV |
| [`san-telmo.md`](san-telmo.md) | la universidad ficticia del adaptador sintético: edificios, titulaciones, calendario |
| [`roadmap.md`](roadmap.md) | lo que falta, ordenado por cuánto creemos que haría falta |
| [`friction-log.md`](friction-log.md) | el registro de fricción con cada API usada, escrito mientras dolía |
| [`management/`](management) | el guion del vídeo y el texto de la candidatura |

Están en inglés a propósito: `use-cases.md` acompaña a los tests, y el resto acompaña a un
repositorio público. El *porqué* de cada decisión técnica está en
[`_hilo/DECISIONES.md`](../_hilo/DECISIONES.md).
