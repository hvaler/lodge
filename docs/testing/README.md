# docs/testing/ — Informes de pruebas

Resultados de ejecución y análisis de cobertura que genera `/testing-patterns` (`results/`).

**configuración** que consume el pipeline (`coverlet.runsettings`, `.security-exceptions.yml`) tampoco:
está en `ops/testing/`.
