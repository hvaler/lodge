# docs/support/ — Soporte en producción

Documentación de soporte y mantenimiento del sistema en producción: registro de incidencias,
niveles de severidad y SLA acordados, flujo de escalado y runbooks de operación.

Lo escribe el equipo. Ningún workflow del ecosistema genera ficheros aquí. Los runbooks de despliegue
que genera `/hv:cicd-init` están en `ops/cicd/`, no aquí. Los requisitos de soporte que exige la
organización están en `_patron/03_Consideraciones_Comunes/`.
